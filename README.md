# DSA practice — Java

Data-structures & algorithms practice in Java (IntelliJ project).

Problems covered so far, under `Palindrome/src/`:

- Palindrome check, pseudo-palindrome (`Pseudo.java`)
- Arrays: diagonal sum, matrix transpose
- Recursion & backtracking: subsets (two variants), combination sum
- Complexity drills: binary-search-style `logN`

Each file is a standalone `main`-runnable exercise; compile and run any of them directly from IntelliJ or `javac`/`java`.
